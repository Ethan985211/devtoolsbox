在日常开发工作中，各种琐碎的工具需求频繁出现：身份证照片需要压缩到200KB以下上传、PDF合同需要提取文字做数据分析、Markdown文档需要转成HTML嵌入网页、一串Base64需要快速解码查看内容……每次遇到这些需求，如果去下载安装专门的软件，不仅耗时费力，还可能在系统中留下一堆长期不用的应用。

一、PDF 处理类（3款）

PDF 是开发者和办公场景中最常见的文档格式，但其封闭性使得编辑和处理变得困难。这三款工具覆盖了 PDF 最常见的操作需求。

1. PDF 文本提取

将 PDF 文件中的文字内容提取为纯文本或可编辑格式。基于 pdf.js 引擎在浏览器端完成解析，支持中英文混排文档、多页 PDF 批量提取。无论是合同条款分析、论文引用提取还是财务对账单整理，直接将 PDF 拖入页面即可获取结构化文本输出。完全离线运行，敏感文档无需担心泄露。

2. PDF 合并

多份 PDF 文件合并为单一文档。使用 pdf-lib 库在浏览器端完成合并操作，支持自定义页面排序、选择性合并（单独抽取所需页面）。典型场景：将多份扫描的发票合并成一个报销文件、把多个章节的技术文档拼接为完整手册。操作简单——拖入文件、调整顺序、一键导出，无需安装任何 PDF 软件。

3. PDF 拆分

将一份多页 PDF 按页拆分为独立文件，或按指定页码范围提取子文档。同样基于 pdf-lib 实现浏览器端处理。适用场景：从大报告中提取特定章节、一份合同只发送相关页面给客户、将双面扫描文档按页分离。拆分后的文件即时下载，原始文件不留存。

二、图片处理类（3款）

图片处理是前端开发、内容创作中最频繁的需求之一。DevToolsBox 的三款图片工具覆盖了压缩、格式转换和尺寸调整三大核心操作，全部使用 Canvas API 在浏览器端完成，零带宽消耗。

4. 图片压缩

在线压缩 PNG、JPEG、WebP 图片，支持质量滑块实时预览压缩效果。核心应用场景：网站截图体积优化加速页面加载、身份证/证件照压缩到指定大小满足上传要求、社交媒体图片批量瘦身。压缩比例可达 70% 以上且肉眼难以察觉画质下降，文件全程在本地处理。

5. 图片格式转换

在 PNG、JPEG、WebP、BMP 等常见格式之间互转。WebP 转 PNG 用于兼容老旧浏览器、JPEG 转 WebP 减小部署体积、BMP 截图转 PNG 便于分享。转换过程纯客户端执行，支持批量拖入多文件同时处理，大幅提升设计素材格式统一的效率。

6. 图片缩放

按像素或百分比精确调整图片尺寸，支持锁定宽高比等比例缩放。常见需求：App 图标生成各尺寸版本、网页 Banner 适配不同设备断点、电商产品图统一规格。直接输入目标尺寸即可获得输出，不需要打开 Photoshop 或 Figma。

三、编码解码类（4款）

前后端开发中频繁接触各种编码格式：API 参数需要 URL 编码、日志中看到 Base64 需要解码查看、HTML 模板需要转义特殊字符……这些工具让你告别手写转义或临时写脚本的麻烦。

7. JSON 格式化

压缩的单行 JSON 瞬间展开为缩进清晰的树形结构，支持语法高亮、折叠节点、一键复制。还提供 JSON 验证功能，快速定位缺失的引号或多余的逗号。后端接口返回的压缩 JSON、配置文件快速阅读、API 调试必备工具。

8. Base64 编解码

支持文本与 Base64 互转、文件到 Base64（Data URL）编码。典型场景：小图标内联到 CSS 减少 HTTP 请求、邮件附件编码传输、解码 JWT Token 的 payload 部分。输入即出结果，支持批量编解码。

9. URL 编解码

中文字符、空格、特殊符号转为合法的 URL 编码格式，以及反向解码。调试 GET 参数时快速查看原始内容、生成带中文参数的分享链接、处理 OAuth 回调中的编码数据。同时支持 encodeURIComponent 和 encodeURI 两种模式。

10. HTML 实体编解码

将 <、>、& 等 HTML 特殊字符与对应的实体编码互转。在网页中嵌入代码示例（防止 XSS）、富文本编辑器的内容净化、邮件模板中特殊字符的处理，这款工具都能快速搞定。支持命名实体和数字实体两种格式。

四、开发辅助与生成器类（8款）

这一类工具是日常开发的"瑞士军刀"——从颜色转换到时间戳、从 UUID 到二维码，每次需求都很小但频率很高，值得一劳永逸地收藏。

11. 颜色转换器

HEX、RGB、HSL、HSV 四种颜色格式互转，附带实时色块预览和调色板选择器。CSS 调色、设计稿取色转代码、透明度 RGBA 快速换算，都在一个页面完成，无需打开任何设计软件。

12. 时间戳转换

Unix 时间戳（秒/毫秒）与人类可读日期时间互转。支持时区选择、实时显示当前时间戳、批量转换。后端日志调试、API 时间参数生成、数据库 timestamp 字段排查时光靠心算太慢，这个工具一秒搞定。

13. 二维码生成器

输入文本或 URL，即时生成可下载的二维码图片。支持调整尺寸、纠错级别、添加中心 Logo。支付码分享、WiFi 密码二维码、App 下载链接推广，应用场景非常广泛。纯前端生成，扫码内容不经过任何服务器。

14. 随机密码生成器

按需生成指定长度和字符集的强密码，支持包含大小写字母、数字、特殊符号的组合。同时标注密码强度等级，一键复制到剪贴板。本地生成，密码不会传输或记录到任何地方——相比在线密码生成服务，零泄露风险。

15. UUID 生成器

一键生成 UUID v4（随机）唯一标识符。支持批量生成、去除连字符、大小写切换。数据库主键生成、分布式系统 ID、文件名去重、前端组件 key 值，无数场景需要 UUID，这个工具让生成变得随手可得。

16. Cron 表达式解析器

输入 Cron 表达式，解析出具体的执行时间点，附直观的人类语言描述。同时提供可视化编辑器，点击即可构建 Cron 表达式。Linux crontab 配置、CI/CD 定时任务调试、K8s CronJob 编写，从此告别 Cron 表达式的手工推算。

17. Markdown 转 HTML

将 Markdown 文本实时渲染为 HTML 代码，支持 GitHub Flavored Markdown 扩展语法（表格、任务列表、代码块语法高亮）。写博客时快速预览效果、生成邮件 HTML 正文、API 文档本地转换，所见即所得，一键复制输出。

18. 文本差异对比

并排对比两段文本的差异，新增行绿色高亮、删除行红色标记、修改行黄色标注。代码 Review 时快速定位改动、配置文件的版本差异分析、合同修改前后的变更追溯，都是文本比较的典型场景。支持逐行和逐词两种对比粒度。

五、其他实用工具（4款）

最后四款工具覆盖网络查询、Unicode 处理、代理浏览和 OCR 识别，虽然不在前四大类中，但使用频率同样不容忽视。

19. IP 地址查询

查询当前公网 IP 地址及归属地信息，包括运营商、国家、城市。支持手动输入 IP 进行查询。服务器部署后验证出口 IP、排查 CDN 是否正确生效、检查 VPN 是否正常工作，一个页面即可完成。

20. Unicode 转换

普通文本与 Unicode 编码（\\uXXXX 格式）互转，支持中文、Emoji 等特殊字符。JSON 数据中遇到 \\u 转义序列时快速查看原文、编程语言中字符串转义的调试、国际化文案处理，这个工具节省大量手动转义时间。

21. 代理浏览器

在页面内嵌入指定 URL 的网页，通过服务端代理实现跨域访问。适用于：临时访问被防火墙限制的站点、绕过 IP 封禁查看竞品页面、检查网站在不同地区的加载情况。提供纯净的浏览环境，不注入任何广告或脚本。

22. OCR 文字识别 API

上传图片进行光学字符识别，提取图片中的文字内容。支持中文、英文、数字混合识别。证件信息数字化录入、扫描文档转可编辑文本、截图中的代码提取，OCR 技术让图片中的文字"活"起来。

为什么选择本地处理的在线工具？

过去几年，大量"免费在线工具"被曝光将用户上传的文件用于训练 AI 模型、出售给第三方数据分析公司，甚至直接泄露到公开网络。DevToolsBox 的设计理念从根本上避免了这一风险：所有运算均在浏览器的 WebAssembly 或 JavaScript 引擎中完成，网络请求仅用于加载页面本身，工具功能不依赖任何后端 API。

这意味着：断网后这些工具依然能正常工作（PWA 安装后），你的 PDF 合同、身份证扫描件、源代码片段绝不会离开本地内存。
