常见问题

      

        

          
什么是 HTML 实体？

          
HTML 实体是用特殊字符串表示保留字符的方式。例如 &lt; 表示 <，&amp; 表示 &。使用实体可以避免浏览器将这些字符误解析为 HTML 标签。

        

        

          
编码和解码有什么区别？

          
编码是将特殊字符（如 <、>、&）转换为对应的 HTML 实体（如 &lt;）。解码是反向操作，将实体还原为原始字符。编码用于安全展示，解码用于还原原文。

        

        

          
数据会不会上传到服务器？

          
不会。所有编解码运算都在你的浏览器本地完成，无需任何 CDN，数据不会离开你的设备。你可以断开网络验证这一点。
