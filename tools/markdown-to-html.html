使用方法

      

        
1在 Markdown 输入框中粘贴或输入你要转换的 Markdown 文本

        
2点击"转换为 HTML"按钮，右侧会同时显示生成的 HTML 代码和实时预览效果

        
3点击"复制 HTML 代码"将 HTML 代码复制到剪贴板，可直接粘贴到网页中使用

        
4如需查看纯文本格式的预览内容，可点击"复制预览文本"按钮

      

    


    

      
使用技巧

      

        
💡支持 GFM（GitHub Flavored Markdown）语法，包括表格、任务列表、删除线等扩展语法。

        
💡生成的 HTML 不包含 <html>、<head>、<body> 等标签，适合直接嵌入已有网页内容区域。

        
💡点击"加载示例"可以快速查看本工具支持的 Markdown 语法效果，方便对比学习。

      

    


    

      
常见问题

      

        

          
生成的 HTML 安全吗？

          
marked.js 默认会对 HTML 标签进行转义，防止 XSS 攻击。原始 Markdown 中的 HTML 代码会被安全处理。如需嵌入原始 HTML，请自行添加 sanitize 配置。

        

        

          
支持哪些 Markdown 语法？

          
支持标准 Markdown 语法和 GFM 扩展，包括标题、粗斜体、链接、图片、列表、代码块、表格、任务列表、删除线、引用、分割线等。

        

        

          
数据会上传到服务器吗？

          
不会。所有转换运算都在浏览器本地完成，Markdown 内容不会离开你的设备。marked.js 通过 CDN 加载后纯前端运行。
