使用方法

1在"原始文本"框中粘贴旧版本内容（例如修改前的代码或配置）
2在"修改文本"框中粘贴新版本内容（例如修改后的代码或配置）
3点击"对比差异"按钮，系统逐行对比并在下方显示差异结果
4绿色背景表示新增行，红色背景表示删除行，无背景色表示未修改行

使用技巧

💡对比结果中绿色高亮（+）是修改后新增的行，红色高亮（-）是被删除的行。两边行号相同表示该行未变。
💡所有对比运算在浏览器本地完成，不会将你的文本上传到服务器。处理敏感代码或配置也无需担心泄露。
💡使用"交换"按钮可以快速互换左右两侧的文本，方便从不同方向查看差异。例如从"删除了什么"切换为"新增了什么"的视角。

常见问题

对比算法是什么？支持大文本吗？
使用经典的 LCS（最长公共子序列）算法进行逐行对比，时间复杂度 O(n×m)。建议单侧文本不超过 5000 行，过大的文本可能导致浏览器卡顿。对于超长文本，建议先分段对比。
支持哪些文本格式？
支持任意纯文本格式，包括代码、配置文件、日志、Markdown、JSON、XML、YAML 等。只要是纯文本，都可以直接粘贴对比。不支持二进制或富文本格式。
对比结果不准确怎么办？
LCS 算法按行对比，如果文本格式差异较大（如大量空行、缩进不同），结果可能不够直观。你可以先使用文本格式化工具（如 JSON 格式化、代码格式化）预处理后再对比，以获得更准确的结果。
