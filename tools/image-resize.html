使用方法

1点击上传按钮，选择你要缩放或裁剪的图片文件（支持 JPG、PNG、WebP 等格式）
2在缩放设置中输入目标宽度和高度，或使用快捷比例按钮快速缩放
3点击"缩放图片"查看预览效果，确认无误后点击"下载图片"保存到本地

使用技巧

💡勾选"保持比例"后只需输入宽度或高度之一，另一个尺寸会自动计算，避免图片变形。
💡放大图片时（如200%）可能导致画质下降。建议使用原始分辨率较高的图片进行放大操作。
💡所有处理完全在浏览器本地完成，图片不会上传到任何服务器，处理大文件也无需担心隐私泄露。

常见问题

支持哪些图片格式？
支持浏览器可识别的所有常见图片格式，包括 JPG、PNG、WebP、BMP、GIF（静态帧）、SVG 等。下载时默认输出 PNG 格式以保持最佳质量。
图片大小有限制吗？
由于使用 Canvas API 处理，图片尺寸受浏览器限制。一般来说，10000×10000像素以内的图片都能正常处理。超大的图片可能导致浏览器卡顿。
如何只裁剪图片的一部分？
本工具目前支持整图缩放。如需裁剪特定区域，可以先指定目标尺寸并在其他工具中完成裁剪，或使用浏览器的开发者工具手动调整 Canvas 参数。
