使用方法

1打开页面后会自动检测并显示你当前的公网 IP 地址，点击"查询我的 IP"可随时重新检测
2如需查询其他 IP，在输入框中输入目标 IP 地址（如 8.8.8.8），然后点击"查询 IP 信息"
3查看返回的详细信息，包括国家、城市、ISP 运营商、组织、ASN 等
4点击"复制结果"可将完整的 IP 信息以文本形式复制到剪贴板

使用技巧

💡本工具使用 ipapi.co 免费 API，查询国内 IP 可能返回的 ISP 信息更为详细。支持 IPv4 和 IPv6 地址查询。
💡如果你使用代理或 VPN，检测到的 IP 地址会是你代理服务器的地址，而非你的真实 IP。
💡IP 地理位置查询的精度通常在城市级别，无法精准定位到具体街道地址。各 API 服务商的数据库也会有差异。

常见问题

IP 地址能精确定位到我的家庭地址吗？
不能。公共 IP 地理位置查询的精度一般只能到城市级别，无法精确定位到具体街道或门牌号。只有运营商和执法部门拥有更精确的数据。
查询 IP 地址会泄露我的隐私吗？
本工具通过 ipapi.co 的 API 查询 IP 信息，API 调用过程中你的 IP 会被用于查询。但查询结果只返回公开可获取的地理位置和 ISP 信息，不会泄露个人身份信息。
为什么我的 IP 显示在其他城市？
IP 地理位置数据库由各 ISP 和第三方维护，可能存在延迟更新。如果你使用了 VPN、代理或移动网络，显示的可能是你接入点的位置而非实际位置。
