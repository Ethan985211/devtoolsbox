# DevToolsBox Notion 开发者模板包

## 模板1：项目管理看板

### 数据库结构
- 数据库名称：项目看板
- 属性：
  - 状态 (Select)：待开始 / 进行中 / 审核中 / 已完成 / 已归档
  - 优先级 (Select)：🔴 紧急 / 🟡 高 / 🟢 中 / ⚪ 低
  - 负责人 (Person)
  - 截止日期 (Date)
  - 标签 (Multi-select)：前端 / 后端 / 设计 / 文档 / Bug / 功能
  - 进度 (Formula)：根据子任务完成率自动计算

### 视图
1. 看板视图 — 按状态分组
2. 时间线视图 — 甘特图
3. 日历视图 — 按截止日期
4. 列表视图 — 详细列表

### 模板页面
- Sprint 计划模板
- 每日站会记录
- Bug 报告模板
- 发布检查清单

## 模板2：代码片段管理器

### 数据库结构
- 数据库名称：代码片段库
- 属性：
  - 语言 (Select)：JavaScript / TypeScript / Python / HTML/CSS / SQL / Bash / 其他
  - 分类 (Select)：工具函数 / React组件 / 数据处理 / API调用 / CSS技巧 / 配置
  - 标签 (Multi-select)
  - 创建日期 (Date)
  - 使用频率 (Select)：⭐ 经常 / 👍 偶尔 / 📌 收藏

### 每个片段页面包含
- 代码块（支持语法高亮）
- 使用说明
- 参数说明表格
- 示例输入/输出
- 相关链接

---

## 模板3：API 文档模板

### 数据库结构
- 数据库名称：API 接口文档
- 属性：
  - 方法 (Select)：GET / POST / PUT / DELETE / PATCH
  - 模块 (Select)：用户 / 商品 / 订单 / 支付 / 其他
  - 状态 (Select)：已实现 / 开发中 / 已废弃
  - 版本 (Text)

### 每个接口页面包含
- 接口路径和方法
- 请求参数表格（参数名 / 类型 / 必填 / 说明）
- 响应示例（JSON）
- 错误码说明
- 调用示例（curl / axios / fetch）
- 变更记录

---

## 导入方法

1. 打开 Notion
2. 点击左侧 "Import"
3. 选择导入方式
4. 调整数据库属性
5. 添加模板页面

## 使用技巧

- 项目看板：配合 Notion Calendar 使用，自动同步截止日期
- 代码片段：安装 Notion Web Clipper，浏览器中快速收藏代码
- API 文档：导出为 PDF 分享给团队
